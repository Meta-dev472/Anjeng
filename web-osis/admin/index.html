Angka Statistik

Hero — Judul & Deskripsi

Teks besar di halaman beranda. Tiga kata pertama (bergerak / berkarya / berdampak) otomatis diberi warna aksen — kata kedua merah.

Galeri Foto

Format: array JSON — { "category": "akademik|seni|olahraga|sosial", "caption": "…", "image": "/foto/nama.jpg" }. Unggah berkas foto ke folder public/foto/ lewat repo GitHub, lalu tuliskan jalurnya di sini.

Kepengurusan Inti

Format: array JSON — { "name": "…", "role": "…", "text": "…", "foto": "" }.

Divisi

Format: array JSON — { "title": "…", "text": "…", "icon": "<path …/>" }. Kosongkan icon untuk kartu tanpa ikon.
